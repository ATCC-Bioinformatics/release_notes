# Data Releases

# Microbial Genomes

This release adds **250 new microbial genome pages** to the ATCC Genome Portal, increasing the customer-facing public collection from **6,750 to 7,000 genomes**.

## Release composition

- **90.0% Bacteriology** (225 items)
- **6.4% Mycology** (16 items)
- **2.8% Virology** (7 items)
- **0.8% Protistology** (2 items)

To see the detailed list of all newly released microbial pages, please [click here](../AGP-assets/2026-Q2/2026-Q2-AGP-New-Genomes.xlsx).

- **98 unique genera**

### Assembly and resistance-associated highlights

- **67 of the 250 released assemblies are represented by a single filtered contig**.
- Resistance phenotype metadata identifies *Citrobacter freundii* [**(ATCC® BAA-2565™)**](https://genomes.atcc.org/genomes/f0070c8ee8134ebe) as resistant to cefazolin and cefoxitin.
- Resistance phenotype metadata identifies *Trichophyton indotineae* [**(ATCC® MYA-5026™)**](https://genomes.atcc.org/genomes/1c5fa157ed3c47bc) as resistant to terbinafine.

# Cell Biology Data

This Q2 2026 release marks the third bulk release of authenticated cell biology datasets available through the ATCC Genome Portal.

### **Release composition**  
  - 49 human cell lines
  - 2 patient-derived organoid models
  

### **65 new datasets**
  - **51 RNA‑seq datasets**
    - Normalized gene-level count files
  - **14 whole‑exome sequencing (WES) datasets**
    - Variant call format files (VCF) with ClinVar annotated variants if applicable

These datasets are available to ATCC Genome Portal Supporting Members and to customers who have purchased physical vials of the corresponding cell lines. 

To see the detailed list of all new release cell biology pages, please [click here](../AGP-assets/2026-Q2/2026-Q2-AGP-New-Cell-Lines.xlsx)
